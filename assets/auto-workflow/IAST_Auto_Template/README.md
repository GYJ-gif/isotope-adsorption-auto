**版本**：v1.4.1  |  **作者**：袁大强  |  **日期**：2026-06-16

## 1. 软件简介

### 1.1 背景

金属有机骨架 (MOF)、共价有机框架 (COF)、氢键有机框架 (HOF) 和多孔有机聚合物 (POP) 等新型多孔材料在吸附分离混合气体方面显示出良好的应用前景。设计和开发具有选择性吸附性能的多孔材料需要了解单组分和混合物的吸附行为。虽然单组分吸附等温线相对容易获得，但是准确的混合物吸附等温线的实验测量是耗时且相对困难的。

Myers 和 Prausnitz 教授于 1965 年提出的**理想吸附溶液理论 (Ideal Adsorbed Solution Theory, IAST)** 是一种仅由单组分吸附等温线数据就可以推导出多组分吸附等温线的方法 [1]。

### 1.2 IAST 基本假设

理想吸附溶液理论基于三个基本假设：

1. 吸附剂具有温度不变的表面积，对于所有吸附质都有相同的表面积
2. 吸附剂在热力学上是惰性的
3. 在恒定的总压和温度下，多组分混合物表现为理想溶液，使得溶液中所有分子之间的平均相互作用强度相等

> ⚠️ 使用 IAST 进行预测计算时，需先检查具体实例是否符合以上假设。关于 IAST 的具体推导过程，可参考 Myers 和 Prausnitz 的原始文献 [1]。

### 1.3 本工具

IASt-Calc 是一个基于 IAST 的多组分气体吸附预测工具。仅需输入纯组分等温线数据，即可预测任意配比、任意总压下的混合气体竞争吸附行为。

### 核心功能

| 功能 | 说明 |
|------|------|
| 等温线拟合 | Auto / DSLF / DSL / SSLF / SSL，Levenberg-Marquardt 多起点优化 |
| 拟合参数标准误差 | 自动计算协方差矩阵，输出参数 ± 标准误 |
| 二元 IAST | 预测两组分混合吸附量、摩尔分数、选择性、分离势 |
| 三元 IAST | 预测三组分竞争吸附行为 |
| 图表输出 | GDI+ 直接绘制（纯等温线、混合吸附、选择性、分离势） |
| 日志输出 | 自动记录完整拟合参数（含标准误）和逐点 IAST 结果 |

### 性能特点

- **纯 C++17**，零第三方依赖
- **可执行文件 < 400 KB**（Python 版 305 MB）
- **R² ≥ 0.9999** 拟合精度
- Marquardt 参数缩放 + 多起点算法，稳定收敛
- 参数自动裁剪（≥1e-6），防止负值

## 2. GUI 使用方法

### 2.1 启动

双击 `iast_calc_gui.exe`。

### 2.2 界面布局

```
┌─ 气体配置区 ─────────────────────────────────────┐

│  G1 y:[__]  G2 y:[__]  G3 y:[__]                │

│  ☐ Ternary (3 gases)        [Run]     [Exit]    │
├─ 图表选择 ───────────────────────────────────────┤
│  Chart:[Pure Isotherms ▼]   [Save Chart][Save Log]│

```

### 2.3 操作流程

1. **加载纯组分数据**：点击 `...` 按钮选择 CSV 文件（两列：`Pressure(kPa), Loading(mmol/g)`）
2. **选择模型**：从下拉菜单选择 Auto/DSLF/DSL/SSLF/SSL（默认 Auto）。Auto 会尝试多种模型；若手动选择的模型拟合较差，也会自动尝试其它模型并择优。
3. **设置初始参数**：可修改参数编辑框中的初始值（格式如 `A1=1,B1=0.1,C1=1,A2=...`）
4. **设置气相组成**：输入各组分摩尔分数 y（二元时 y1+y2=1）
5. **设置总压列表**：逗号分隔 kPa 值，留空则自动生成 1~105 共 20 个点
6. **设置输出前缀**：结果文件名前缀
7. **三元模式**：勾选 Ternary 复选框，Gas3 行出现，填写 y3
8. **开始计算**：点击 Run
9. **切换图表**：用 Chart 下拉菜单切换视图
10. **保存**：Save Chart 导出 PNG，Save Log 保存完整日志

### 2.4 输出文件

| 文件 | 内容 |
|------|------|
| `iast_calc_gui.exe 所在目录/IAST_final/{prefix}_Selectivity.csv` | 逐点 IAST 结果 |
| `iast_calc_gui.exe 所在目录/IAST_final/{prefix}_log.txt` | 完整计算日志（含拟合参数 ± 标准误、候选模型评分） |
| `iast_calc_gui.exe 所在目录/IAST_final/{prefix}_*.svg` | 自动导出的等温线、混合吸附、选择性和分离势图 |
| `{prefix}_chart.png` | 手动点击 Save Chart 时保存的当前图表截图 |

## 3. CLI 使用方法

### 3.1 编译

```batch
call "C:\BuildTools\VC\Auxiliary\Build\vcvars64.bat"
cl /O2 /utf-8 /EHsc /std:c++17 /Fe:iast_calc.exe iast_cli.cpp
```

### 3.2 命令行参数

```
iast_calc.exe
  --gas1 C2H4       气体1名称
  --csv1 C2H4.csv   气体1等温线数据
  --model1 Auto     模型 (Auto/DSLF/DSL/SSLF/SSL)
  --init1 A1,B1,C1,A2,B2,C2  初始参数（可省略）

  --gas2 C3H6       气体2名称
  --csv2 C3H6.csv   气体2等温线数据
  --model2 DSLF     模型

  --gas3 CH4        气体3（三元模式）

  --y1 0.5 --y2 0.5  摩尔分数
  --pressures 1,2,...,100  总压列表(kPa)
  --prefix result   输出前缀
```

## 4. 输入文件格式

CSV 格式，UTF-8 或 ANSI：

```csv
Pressure(kPa),Loading(mmol/g)
0.0646373,0.009464286
0.131,0.019393304
...
```

- 第一行为列标题，程序自动识别
- 双精度浮点数
- 建议 ≥20 个数据点，覆盖低/中/高压区
- **必须包含低压区数据**（<1 kPa）

## 7. 技术细节

### 7.1 优化器

- **算法**：Levenberg-Marquardt (LM)
- **多起点**：默认 5 个初始点，对数均匀扰动 [0.1, 10]
- **Marquardt 缩放**：Jacobian 列归一化，避免跨数量级尺度失衡
- **正约束**：参数裁剪 ≥ 1e-6
- **线搜索**：20 步回溯，α 减半

### 7.2 自动模型选择

Auto 模式会按从简单到复杂的顺序尝试四种模型：

```text
SSL -> DSL -> SSLF -> DSLF
```

程序不会简单选择第一个能拟合的模型，而是对所有候选模型计算 BIC 分数：

- `chi²` 越小，说明拟合残差越小；
- 参数越少，模型越简单，BIC 会给更低惩罚；
- 当简单模型和复杂模型拟合效果接近时，优先选择简单模型；
- 只有复杂模型显著改善拟合质量时，才会选择 DSL/SSLF/DSLF。

如果用户手动选择某个模型，而该模型拟合结果较差（例如 R² 低于阈值），程序也会自动尝试其它模型并在日志中记录候选模型评分和最终选择结果。

### 7.3 参数标准误差

拟合收敛后通过 Jacobian 协方差矩阵计算：

$$\text{Var}(\hat{\beta}) = \sigma^2 (J^T J)^{-1}, \quad \sigma^2 = \frac{\text{RSS}}{n-m}$$

使用 Gauss-Jordan 求逆，跳过主元 < 1e-15 的近奇异列。日志中以 `±` 格式输出。

### 7.4 已知限制

- 缺乏亚 kPa 数据时低压区外推不可靠
- 三元 IAST 高覆盖度时 Newton 法收敛性下降
- C++ LM 在非凸问题上可能陷局部极小值（精度弱于 Python L-BFGS-B）
